## 🔄 Generate New Posts


```bash

```

### Option 3: Single Post
```bash

```

### Option 4: Custom Python Script
```python
from linkedin_agent import LinkedInAgent

agent = LinkedInAgent()
post = agent.generate_post(post_type="tip")
agent.display_post(post)
agent.save_post(post, "my_post.json")
```
